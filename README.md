# Phase 2 分析笔记

## 汇编逐行解析
| 汇编指令 | 含义 | 核心作用 |
|----------|------|----------|
| `sub $0x28,%rsp` | 开辟40字节栈空间 | 为6个int数字预留存储位置 |
| `call read_six_numbers` | 读取6个数字到栈顶 | 输入的6个数字按顺序存在rsp开始的栈空间 |
| `cmpl $0x1,(%rsp)` | 校验第一个数字是否为1 | 第一个数字必须为1，否则触发爆炸 |
| ... | ... | ... |

## 调试过程
1.  给`phase_2`和`explode_bomb`设置断点，避免程序直接退出
2.  反汇编`phase_2`，识别循环初始化、循环条件、数值校验逻辑
3.  用`x/6wd $rsp`查看栈上输入的6个数字，验证规律

## 核心逻辑
Phase 2 是6个数字的循环校验，核心规律为：第一个数字固定为1，后续每个数字 = 前一个数字 × 2。

## 核心知识点
- x86-64汇编的循环结构实现
- 被调用者保存寄存器（rbx/rbp）的使用规则
- 栈空间的布局与内存查看方法
